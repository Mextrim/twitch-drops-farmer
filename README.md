## Зачем

Twitch Drops капают, пока ты смотришь канал с включёнными дропами. Но:

- нужные каналы надо искать вручную по играм;
- они постоянно уходят в офлайн;
- держать вкладку с включённым звуком неудобно.

Расширение делает это само: спрашивает у Twitch список стримов **с включёнными
дропами**, ранжирует их и крутит по таймеру в фоновых вкладках.

> **Ничего не подделывается.** Это обычные вкладки с обычным плеером Twitch.
> Прогресс считает сам Twitch. Токен аккаунта не запрашивается и не хранится.

## Установка

<details open>
<summary><b>Chrome / Edge — распакованное расширение</b></summary>

1. Откройте **`chrome://extensions`** (в Edge — `edge://extensions`).
2. Включите **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Укажите папку `dist/twitch-drops-farmer` (соберите её командой `npm run build`).
5. Закрепите иконку на панели задач: кнопка «пазлик» → *Twitch Drops Farmer* → «Закрепить».

</details>

<details>
<summary><b>Из архива</b></summary>

Распакуйте `dist/twitch-drops-farmer-1.0.0.zip` — внутри уже готовая к загрузке папка.

</details>

> Нужен **Chrome/Edge 120+** и **авторизация в Twitch** в этом же браузере:
> без входа дропы не засчитываются.

Подробности и разбор проблем — в [INSTALL.md](INSTALL.md).

## Как это работает

![Архитектура](docs/architecture.svg)

Ключевая идея: у каждого стрима в GraphQL Twitch есть свободные теги
`freeformTags`. Когда на канале включены дропы, среди них появляется
`DropsEnabled` — и его можно передать **в фильтр на стороне Twitch**:

```graphql
query Farm($id: ID!) {
  game(id: $id) {
    name
    streams(options: { sort: VIEWER_COUNT, freeformTags: ["DropsEnabled"] }) {
      edges { node { viewersCount channel { name displayName } } }
    }
  }
}
```

Ответ содержит только каналы с дропами — без перебора и лишних запросов.

> ⚠️ **Тонкость:** фильтр работает **только как литерал в тексте запроса**.
> Если передать `freeformTags` через `variables`, эндпоинт вернёт 0 строк.
> Поэтому в `twitch-api.js` запрос собирается конкатенацией строки, а
> `npm run check` следит, чтобы это не «оптимизировали» случайно.

## Возможности

| | |
|---|---|
| 🎯 **Поиск по играм** | Добавляете игры — расширение находит каналы с дропами среди всех стримов игры |
| 🔄 **Ротация** | От 1 до 4 вкладок одновременно, смена канала по таймеру |
| 🛡 **Проверка онлайна** | Каждые 2 минуты один батч-запрос на все слоты (20 каналов за раз) |
| 🔇 **Тихий режим** | Автоматический mute и качество 160p — трафик почти не тратится |
| ⏭ **Умный пропуск** | Если на странице канала нет тега `DropsEnabled` — слот сразу переключается |
| 🔔 **Уведомления** | Браузерное уведомление, когда дроп засчитан |
| 🚫 **Стоп-слова** | Каналы с нежелательными словами в названии не берутся |
| 🧠 **MV3-safe** | Состояние в `chrome.storage`, расписание на `chrome.alarms` — service worker выгружается без потерь |
| 🔒 **Минимум прав** | `storage`, `alarms`, `tabs`, `notifications` + два хоста. Ничего лишнего |

## Настройки

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Игры | — | Список игр для поиска каналов |
| Одновременных каналов | 1 | Сколько вкладок держать открытыми (1–4) |
| Минут на канал | 15 | Сколько смотреть перед переключением |
| Обновлять пул, мин | 20 | Как часто переспрашивать Twitch |
| Минимум зрителей | 0 | Отсекает каналы с пустым онлайном |
| Без звука | вкл | Mute на фарм-вкладках |
| Качество 160p | вкл | Экономит трафик |
| Восстанавливать качество | вкл | Возвращает прежнее качество после остановки |
| Пропускать без дропов | вкл | Уходит с канала без тега `DropsEnabled` |
| Уведомлять о дропах | вкл | Уведомление при получении |
| Продолжать после перезапуска | вкл | Продолжает фарм при старте браузера |

## Разработка

```bash
npm run check     # манифест, import-пути, синтаксис, соглашения
npm run test      # самотест движка на живом API Twitch
npm run build     # сборка dist/ + zip
npm run icons     # перегенерация иконок
npm run serve     # предпросмотр UI на http://localhost:8123
```

`npm run test` поднимает настоящий обмен с Twitch: discovery, пул, слоты,
ротация, реакция на офлайн, остановка.

Предпросмотр интерфейса без установки расширения:

```
http://localhost:8123/tools/ui-preview/index.html?page=popup
http://localhost:8123/tools/ui-preview/index.html?page=options
```

## Ограничения

- Пул ограничен тем, что отдаёт Twitch: ~10 каналов на игру за запрос.
  Расширение делает два запроса с разной сортировкой (`VIEWER_COUNT` и `RECENT`),
  поэтому пул обычно вдвое больше.
- Онлайн-статус берётся из API, а не из DOM: на странице Twitch плеер может быть
  перекрыт диалогом, и вердикт «офлайн» получался бы ложным.
- Тег `DropsEnabled` в шапке канала рендерится с задержкой, поэтому первые
  25 секунд расширение отвечает «не знаю» и не переключает канал наугад.
- Стримы грузятся на 160p — трафик уменьшается, но не обнуляется.

## Ответственность

Автоматизация просмотра находится в серой зоне правил Twitch. Расширение
сделано максимально «честно» — обычные вкладки с обычным плеером, — но риск
блокировки аккаунта исключить нельзя. Используйте на свой страх и как вам уместно.
