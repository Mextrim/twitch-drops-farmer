# Установка

Три шага, потом расширение работает само.

## 1. Загрузить расширение

1. Откройте **`chrome://extensions`** (в Edge — `edge://extensions`).
2. Включите тумблер **«Режим разработчика»** в правом верхнем углу.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Укажите папку `dist/twitch-drops-farmer` внутри проекта:

   ```
   <папка проекта>\dist\twitch-drops-farmer
   ```

   Выбирать нужно именно её — ту, где лежит `manifest.json`, а не родительскую.

5. Расширение появится в списке. **Закрепите его иконку** на панели задач:
   нажмите на кнопку «пазлик» справа от адресной строки → найдите
   *Twitch Drops Farmer* → нажмите «Закрепить».

> Если выбрать папку с `tools/` внутри — Chrome её не примет. Для установки
> используйте чистую папку из `dist/`.

## 2. Настроить

Расширение само откроет страницу настроек. Введите название игры —
например `VALORANT` — и нажмите «Найти и добавить». Добавьте нужные игры,
затем нажмите «Запустить».

Проверить, что дропы капают: откройте `https://www.twitch.tv/drops/inventory`
и убедитесь, что у вас есть активные дропы и вы залогинены в этом браузере.

## 3. Автозапуск (уже настроен)

В папке автозагрузки Windows создан ярлык, который открывает браузер
сразу с расширением:

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Twitch Drops Farmer.lnk
```

При входе в Windows браузер поднимется в свёрнутом виде, а расширение
продолжит фарм с того места, где остановился.

Убрать автозапуск: `Win + R` → `shell:startup` → удалить ярлык.
Пересоздать: `node tools/setup-autostart.ps1`

## Если что-то пошло не так

**Иконка не появилась, а настройки открываются пустыми.**
Проверьте `chrome://extensions` — расширение должно быть без ошибок (красная
плашка «Ошибки» отсутствует). Если есть — нажмите «Обновить» (круговая стрелка)
на карточке расширения.

**Фарм не стартует сам после перезапуска браузера.**
Откройте настройки расширения и проверьте галочку
«Продолжать фарм после перезапуска браузера».

**Каналы не находятся.**
В журнале на странице настроек будет строка с причиной. Чаще всего это
точность названия игры: `game(name:)` ищет по точному имени
(`League of Legends` найдётся, `лол` — нет). У каналов с дропами есть
тег `DropsEnabled`; если его нет ни у кого в игре — пул будет пуст, это
нормально, попробуйте другую игру.

**Прогресс не идёт.**
Проверьте, что вкладка канала действительно играет, а не стоит на паузе:
Twitch не считает дропы, если видео не воспроизводится. Расширение принудительно
ставит 160p — это экономит трафик, но не отключает воспроизведение.
